# Java Fundamentals & Object-Oriented Programming

A collection of Java programming exercises developed as part of my learning journey in programming and Object-Oriented Programming (OOP).

## About This Repository

This repository contains Java practice exercises covering fundamental programming concepts and introductory Object-Oriented Programming.

The projects are created to improve programming skills, strengthen logical thinking, and understand how Java works through hands-on practice.

## Topics Covered

- Java Fundamentals
- Variables and Data Types
- Conditional Statements
- Loops
- Arrays
- Methods
- Classes and Objects
- Object-Oriented Programming (OOP)

## Technologies

- Visual Studio Code
- NetBeans
- Git & GitHub

## Goals

- Practice Java programming.
- Understand fundamental programming concepts.
- Develop problem-solving skills.
- Build a strong foundation in Object-Oriented Programming.
